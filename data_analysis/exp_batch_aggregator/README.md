# 实验工况汇总脚本

依据《本征动力实验工况标记.xls》中记录的 **批次 → 流道 → 工况（数据图标签格式）** 对应关系，
把各批次、各流道的实验结果文件按**相同的实验自变量设置**分组复制到同一个文件夹，
并在文件名前加上该批次的日期前缀，以便区分不同批次的实验。

## 文件说明

| 文件 | 用途 |
|---|---|
| `exp_cond_summarizer.py` | 主脚本 |

## 环境准备

本模块与项目内其他模块共用同一个 Conda 环境，依赖清单统一放在仓库根目录 `requirements-data-analysis.txt`：

```bash
# 在仓库根目录执行
pip install -r requirements.txt
```

本模块实际用到的依赖仅 `pandas`、`openpyxl`、`xlrd` 三个（分别用于读取 xls/xlsx 与写出）。

## 快速开始

```bash
python exp_cond_summarizer.py \
    --xls    "本征动力实验工况标记.xls" \
    --input  "0828_μmax_revision" \
    --output "实验结果汇总"
```

**强烈建议先加 `--dry-run` 预览**，确认解析结果无误后再实际执行：

```bash
python exp_cond_summarizer.py --xls "本征动力实验工况标记.xls" \
    --input "0828_μmax_revision" --output "实验结果汇总" --dry-run --verbose
```

## 参数

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `--xls` | 是 | — | 工况标记文件（xls/xlsx），记录 批次→流道→工况 的对应关系 |
| `--input` | 是 | — | 输入文件夹，即包含各日期子文件夹（如 `20260719`）的实验数据根目录 |
| `--output` | 是 | — | 输出文件夹，将按工况标签建立子文件夹 |
| `--hours` | 否 | `96` | 培养时长，用于拼接结果文件路径（对应 `96小时` 目录） |
| `--sheet` | 否 | 自动 | 工况标记文件中的工作表名或索引；默认自动选用第一个非空工作表 |
| `--dry-run` | 否 | 关 | 仅预览将执行的操作，不实际复制文件 |
| `--on-conflict` | 否 | `overwrite` | 目标文件已存在时的处理：`overwrite`（覆盖）或 `skip`（跳过） |
| `--verbose` | 否 | 关 | 输出解析细节（批次位置、跳过的行等） |

## 输入 / 输出结构

**输入**（脚本只读取，不修改源文件）：

```
<input>/<YYYYMMDD>/数据汇总/03_可视化结果/<N>小时/CH<k>_可视化结果_<N>.xlsx
```

例如：

```
0828_μmax_revision/20260719/数据汇总/03_可视化结果/96小时/CH8_可视化结果_96.xlsx
```

**输出**（按工况标签分文件夹，文件名加日期前缀）：

```
<output>/<工况标签>/<YYYYMMDD>_CH<k>_可视化结果_<N>.xlsx
```

例如：

```
实验结果汇总/L210-N300-IC10%/20260719_CH8_可视化结果_96.xlsx
实验结果汇总/L120-N160-IC5.25%/20260504_CH1_可视化结果_96.xlsx
实验结果汇总/L120-N160-IC5.25%/20260504_CH2_可视化结果_96.xlsx
实验结果汇总/L120-N160-IC5.25%/20260712_CH3_可视化结果_96.xlsx
```

同一工况文件夹下，不同批次的实验以日期前缀区分。

## 解析逻辑

脚本不依赖固定的行列号，按以下规则自动定位：

1. **找批次**：扫描所有非空单元格，凡同时包含「批次实验」和 `YY-MM-DD` 日期
   （如 `26-05-04`）的单元格即为一个批次标题。
2. **定列区间**：同一行可能并排放置多个批次（如第1批次在左、第3批次在右），
   此时以同行右侧相邻批次的起始列作为本批次列区间的右边界，避免串行读入隔壁批次的数据。
3. **找表头**：在本批次列区间内、批次标题行之后，寻找同时包含「流道编号」和
   「数据图标签格式」的表头行，并按表头文字定位各列列号。
   xls 的列顺序变化时依然能正确解析。
4. **读数据**：表头行之下、下一个批次标题行之前的所有行，
   凡「流道编号」与「数据图标签格式」两列均有值的行，即为一条 批次-流道-工况 记录。
5. **日期转换**：批次标题中的 `26-05-04` → 数据文件夹 `20260504`，同时作为文件名前缀。

因此，只要工况标记文件保持「批次标题 + 表头行 + 数据行」的组织方式，
即使新增批次、调整列顺序或左右并排布局，脚本都能正确工作。

## 注意事项

- 脚本**只复制，不移动、不删除**源文件；目标已存在文件按 `--on-conflict` 处理（默认覆盖）。
- 若某条记录在输入文件夹中找不到对应文件，脚本会**跳过该条并打印警告**，
  不影响其余记录的执行，最后统一列出所有缺失项，便于排查。
- 若同一工况下出现重名目标文件（同一日期同一流道被登记两次），脚本会打印警告并提示后者覆盖前者。
- 工况标签中的特殊字符（如不间断连字符 `‑`、`%`、`/` 等）会原样保留为文件夹名。
