B. 最优点不是“单因子最优的叠加”：条件最优点随其他因子移动
==============================================================================
条件最优: d(yhat)/dxi = 0  ->  xi* = -(bi + bij*xj + bik*xk) / (2*bii)

背景 (其余两因子水平)      x1* 光照   x2* 氨氮   x3* 无机碳
(-1,-1) 都低                 -0.167     +1.093     +0.753
(0,0) 都居中                  +0.335     +0.962     +0.703
(+1,+1) 都高                 +0.838     +0.831     +0.653

逐个因子的条件最优（其余两因子固定为 -1 / 0 / +1）:
  x1 光照: 背景-1 -> -0.167 | 背景0 -> +0.335 | 背景+1 -> +0.838   移动幅度 +1.004 编码单位
  x2 氨氮: 背景-1 -> +1.093 | 背景0 -> +0.962 | 背景+1 -> +0.831   移动幅度 -0.263 编码单位
  x3 无机碳: 背景-1 -> +0.753 | 背景0 -> +0.703 | 背景+1 -> +0.653   移动幅度 -0.100 编码单位

对比：忽略交互项时的“独立最优” xi** = -bi/(2*bii):
  (+0.335, +0.962, +0.703)   该处 yhat = 0.206422
