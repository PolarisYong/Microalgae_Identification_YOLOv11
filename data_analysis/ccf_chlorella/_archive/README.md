## 归档原因

1. 单位标注为 d⁻¹，与项目确认的 h⁻¹ 不一致，参考价值有限；
2. 产物不完整——`summary.json` 记录的 `CCF_小球藻_20组模拟数据_μmax.xlsx` 已不存在；
3. 功能被 `../ccf_from_table.py` 完全取代，后者使用真实实验数据，才是可汇报的结果。

若确需复用模拟数据版，必须先做两件事：
把 42 处 `d⁻¹` 全部改为 `h⁻¹`，并连同 `run_log.txt` 中的数值说明一起复核物理含义。
