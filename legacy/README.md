# legacy —— 历史版本与一次性脚本

本目录**不参与当前主流程**，仅为历史追溯保留。归档原则：

- **算法迭代快照**：已被当前实现取代，但绑定了历史批次的实验参数，删除后无法复现旧结果。
- **一次性脚本**：针对某个具体批次或某次汇报写死路径，复用会造成误操作。
- **被删依赖的下游脚本**：其依赖的模块已按重构要求删除，单独保留会立即报错。

需要复用其中某个算法时，请先把脚本内的硬编码路径改造成配置驱动，再迁回对应模块目录。

| 子目录 | 内容 |
|---|---|
| `detection/` | `microalgae_dense_hybrid_01~03.py` —— `detect_batch.py` 的前身，腔室掩膜过滤与掩膜修复的演进过程 |
| `processed_versions/` | `02/05/07_processed_batch.py` —— 生长曲线拟合算法的迭代快照（02→05→07→08），各自绑定 20260609 / 20260726 / 20260712 批次的参数与 `PARAM_MAPPING` |
| `research/` | 训练推理实验脚本（`run_inference_full.py` 等，依赖已删除的 `microalgae_dense_hybrid_00`）、一次性改名/提取/清理脚本、测试残留产物 |

对应关系见 [`docs/migration_map.md`](../docs/migration_map.md)。
